# RPG魔法辞典 執筆ガイド v1

目的：読んだ人に「あったなー」とニヤッとしてもらう。正確なデータの上に、遊んだ人しか知らない手触りをひとさじ乗せる。攻略本の余白の書き込みくらいの温度で書く。

## 1. ニヤッとさせる3つの型（1ページに1つで十分）

| 型 | 書き方 | こう書く | こうは書かない |
|---|---|---|---|
| 手癖 | 意識していなかった操作・習慣を具体的に | リストの左上にあるから、とりあえずファイア。 | 序盤で使いやすい便利な魔法です。 |
| 擬人化 | 覚える・頼る・ゆずる・引退する | ファイラが来た日、主役をゆずる。 | 中盤以降は上位魔法が推奨されます。 |
| 数字の驚き | 2つの数字を並べて逆転を見つける（出典必須） | Lv30までは、死より呪いのほうが高い。 | 料金はレベルに応じて変化します。 |

## 2. 事実・思い出・想像を分ける

- **事実**：名前・値段・消費・対象・系統。出典が2つ以上あるものだけ。データ欄と表に置く。
- **思い出**：多くの人に当てはまる遊び方。過去形で。「必ず」「誰もが」は使わない。
- **想像**：考察の「ここからは想像」の段だけ。「〜かもしれない」で結ぶ。魔法詳細には入れない。

## 3. パーツ別

- **見開きの一文**（`stories.json` の `lead`）：1〜2文、各20字前後。トップに単体で出ても意味が通ること。
- **章の題**（`chapters[].title`）：各15字前後。出会い → 定番 → 交代 → それでも使う が基本。攻撃以外は「交代」を「頼られる場面」に替えてよい。
- **章の本文**（`chapters[].body`）：80〜140字。1文目に事実、2文目以降に手触り、最後を短く。
- **考察の見出し**：30字以内。数字か出来事で言い切る。
- **問いかけ**（`ask`）：20字前後。一言で答えられる具体的な問い。

## 4. 言葉づかい

- 本文は「だ・である」、注記は「です・ます」。
- 魔法名・用語は各作品の日本語版の表記どおり。
- 作品名は初出で正式名、以降は略称。
- ザコ・レベル上げ・全体化など、遊んだ人の言葉はそのまま使う。
- 英語版は直訳せず、英語版の魔法名で同じ型で書き直す。

## 5. やらないこと

攻略の指示／大げさな言葉（伝説の・最強の）／あらすじ・キャラ紹介／予告なしのネタバレ／記憶だけで書く／他サイトの文章の流用（攻略サイトは数字の確認にだけ使う）。
