# 「段階の表し方」の型分け：仕様（分析担当のサブエージェント向け）

サイトに「魔法世界の設計図」という、作品を横断した構造分析のページを作ります。最初のテーマは**段階の表し方**です。弱い魔法から強い魔法へ、名前の上で段階をどう表しているかを作品ごとに型に分け、創作者（小説・TRPG・ゲーム制作）が自分の魔法体系を考えるときの材料にします。

例：DQ「メラ → メラミ → メラゾーマ」（語形が変わる）、FF「ファイア → ファイラ → ファイガ」（共通の語尾）、メガテン「アギ → アギラオ → アギダイン」（共通の語尾）、MOTHER「PKファイアー α → β → γ → Ω」（記号）。

## 入力と出力

- **入力**（読むだけ）：`/Users/kobayashi/GitHub-personal/mahou-jiten/tools/research/out/stage/input-<担当キー>.json`
  - 作品ごとに `overview`・`rules`・`growth`（サイトに載せている魔法体系の説明）と、系統ごとの魔法の並び（`series`）、系統に属さない魔法（`singles`）が入っています。
  - `members` は `[名前, tier, 範囲, fx, el, line]` の配列です。tier は段階（1が最弱）。`line: "all"` は全体化した版。
- **出力**：`/Users/kobayashi/GitHub-personal/mahou-jiten/tools/research/out/stage/stage-<担当キー>.json`
  - 作品を数本調べるたびに、その時点までの内容で書き出して保存してください。
  - 書き終えたら `node -e "JSON.parse(require('fs').readFileSync(process.argv[1]))" <path>` で読めることを確認してください。
- サイトのデータ（`astro/src/data/`）は書き換えないでください。

## 守ること

- **入力にある材料だけで判断する。** 例に挙げる魔法名は、入力の `series`・`singles` に実際にある名前だけを使う。記憶で名前を足さない。Web検索もしない。
- 材料が足りず判断できないときは、推測で埋めずに `confidence: "low"` にして `issues` に書く。
- シリーズの各作品（`group` がある作品）は、代表作品と同じ型なら `sameAsGroup: true` にして、違いだけを書けばよい。違いがある場合（例：FFI だけ別の方式）は必ず書く。
- 説明は自分の言葉で短く書く。入力の文章をそのまま写さない。

## 型（type）の定義

| type | 意味 | 例 |
|---|---|---|
| `morph` | 語形変化。元の語の一部を残しつつ、系統ごとに違うやり方で形を変える | メラ → メラミ → メラゾーマ |
| `suffix` | 共通の語尾。どの系統でも同じ語尾を付け替える・付け足す | ファイア → ファイラ → ファイガ、アギ → アギラオ → アギダイン |
| `prefix` | 共通の頭の語。どの系統でも同じ語を前に付ける（大・ハイ・メガなど） | （入力から探す） |
| `symbol` | 記号・数字・文字を付ける（α/β/γ/Ω、II/III、＋など） | PKファイアー α → β |
| `compound` | 元の語は残し、別の語と組み合わせて段階を作る（後ろの語が変わる等） | （入力から探す） |
| `distinct` | 段階ごとに名前のつながりがない（意味やイメージだけでつながる） | （入力から探す） |
| `same-name` | 名前は変えず、魔法レベル・熟練度・使用回数・装備などで強くなる | （入力から探す） |
| `none` | 段階という考え方がほぼない（系統が1段だけ、または魔法が少ない） | |
| `other` | どれにも当てはまらない。`description` で詳しく書く | |

- 1つの作品が複数の型を使っていることは普通にある（例：DQ は `morph` が主で、ベ・マを付ける `prefix` 的な例もある）。いちばん多い型を `primary`、ほかを `secondary` にする。
- `suffix` と `morph` の境目：同じ語尾の組（ラ・ガ、ラオ・ダインなど）が**3つ以上の系統**で共通なら `suffix`、系統ごとにばらばらなら `morph`。

## 範囲の表し方（scope）も一緒に見る

段階と混ざりやすいので、範囲（単体 → 全体）を名前でどう表しているかも分ける。

| type | 意味 | 例 |
|---|---|---|
| `separate-name` | 単体版と全体版を別の名前にする | スカラ／スクルト |
| `affix` | 範囲を表す語を付ける | アギ → マハラギ（マハ〜） |
| `toggle` | 同じ名前のまま、使うときに範囲を切り替える | |
| `tier-linked` | 段階が上がると範囲も広がる（範囲専用の名前はない） | ザキ → ザラキ |
| `none` | 範囲を名前で表さない、または範囲が固定 | |
| `other` | どれにも当てはまらない | |
