# 作品の発売日と機種：仕様（調査担当のサブエージェント向け）

サイトに「時代背景」「ゲームの進化」の読み物を作るため、収録している作品ごとに**最初に発売された日と機種**を調べます。「この魔法体系は、いつ・どの機種の時代に生まれたか」を並べる材料にします。

## 入力と出力

- **入力**（読むだけで、書き換えない）：`/Users/kobayashi/GitHub-personal/mahou-jiten/astro/src/data/games.json`
  - 担当の作品は依頼文に id で書いてあります。`name`（正式タイトル）と `basis`（サイトが基準にした版）を見て、どの作品かを確かめてください。
- **出力**：`/Users/kobayashi/GitHub-personal/mahou-jiten/tools/research/out/release/release-<担当キー>.json`
  - 数本調べるたびに、その時点までの結果で上書き保存してください（途中で止まっても結果が残るように）。

## 何を調べるか

- **date**：その作品が**世界で最初に発売された日**。ほぼすべて日本が最初です（Wizardry だけ米国）。
  - 形式は `"YYYY-MM-DD"`。日が分からなければ `"YYYY-MM"`、月も分からなければ `"YYYY"`。推測で日を埋めない。
  - `basis` の版ではなく、その作品の最初の版です。例：テイルズ オブ ファンタジアは PS 版（1998）ではなく SFC 版（1995）。英雄伝説 空の軌跡FC は PSP 版ではなく Windows 版（2004）。
  - リメイクやリマスターのタイトル（『ペルソナ5 ザ・ロイヤル』など）は、そのタイトル自体の最初の発売日。元の作品の日付は note に書く。
  - オンラインゲームは正式サービスの開始日（βテストは含めない）。
  - 予約特典・限定版の先行発売ではなく、通常の発売日。
- **platforms**：その日に発売された機種（同じ日に複数機種で出たときだけ複数）。後から移植された機種は入れない。
  - 名前は次の表記にそろえる：`Apple II`、`ファミリーコンピュータ`、`スーパーファミコン`、`ゲームボーイ`、`ゲームボーイアドバンス`、`PCエンジン SUPER CD-ROM²`、`メガドライブ`、`メガCD`、`セガサターン`、`プレイステーション`、`プレイステーション2`、`プレイステーション3`、`PlayStation 4`、`PlayStation 5`、`ニンテンドー64`、`ニンテンドーDS`、`ニンテンドー3DS`、`Wii`、`Nintendo Switch`、`Windows`、`Xbox Series X|S`
  - 表にない機種が必要なときは、メーカーの正式な日本語名を使い、report に書く。
- **note**（必要なときだけ、1〜2文）：
  - 最初の発売が日本以外のとき：日本での最初の発売日と機種。
  - リメイク・完全版のタイトルのとき：元の作品の発売日と機種。
  - オンラインゲームで大きな作り直しがあったとき（例：FFXIV の新生エオルゼア）：その日付。
  - 資料どうしで日付や機種が食い違ったとき：採用しなかった値と、その資料。
- **src**：確かめた資料。1件以上。
  - まず日本語版 Wikipedia の**その作品の記事**（シリーズの記事ではなく）。基本情報の表と本文の両方を見る。
  - メーカー公式の製品ページや、発売当時の記事（ファミ通.com など）で確かめられたら2件目に足す。必須ではない。
  - `title` は `Wikipedia「記事名」` や `スクウェア・エニックス公式「製品名」` の形。`url` はそのページのURL（日本語のままでよい）。

## 特別な作品

- `dq`（ドラゴンクエスト（シリーズ））：シリーズ第1作『ドラゴンクエスト』の発売日と機種を入れ、note に「シリーズ第1作『ドラゴンクエスト』の発売日」と書く。
- `ff`（FINAL FANTASY V）、`smt`（真・女神転生III-NOCTURNE）、`persona`（ペルソナ5 ザ・ロイヤル）は代表作品ですが、ふつうにそのタイトルの発売日を調べる。

## 進め方

- 文字化けや取得できないページは、URLの前に `https://r.jina.ai/` を付けると読める。出典には元のURLを書く。
- 記事が見つからない、または日付が確かめられない作品は、分かった範囲（年だけなど）を入れて report に書く。空欄にはしない。

```jsonc
  "report": "作品ごとに、確かめ方（基本情報と本文が一致したか、2件目の資料があるか）と、迷ったところ"

```
（上の例の日付は形式の見本です。値はかならず資料で確かめてください。）
