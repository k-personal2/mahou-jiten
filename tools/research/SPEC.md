# RPG魔法の言い換え辞典：調査データ仕様（調査担当のサブエージェント向け）

サイトの目的は、同じ役割の魔法がRPG作品ごとにどう呼ばれているかを、作品を横断して比較することです。攻略サイトではありません。
例：炎の攻撃魔法は、DQ「メラ」、FF「ファイア」、メガテン「アギ」、MOTHER「PKファイアー」、Wizardry「ハリト」。

- **既存データ**（読むだけで、書き換えない）：`/Users/kobayashi/GitHub-personal/mahou-jiten/astro/src/data/`
  - `magics.json`：1行に魔法1件
  - `games.json`：作品
  - `systems.json`：作品ごとの魔法体系
  - `effects.json`：用途と細分類（kinds）
  - `elements.json`：属性
- **出力先**：`/Users/kobayashi/GitHub-personal/mahou-jiten/tools/research/out/<担当キー>.json`
  - 作品を1つ調べ終えるたびに、その時点までの内容で書き出して保存してください。途中で止まっても結果が残るようにするためです。
  - 書き終えたら `node -e "JSON.parse(require('fs').readFileSync(process.argv[1]))" <path>` で、JSONとして読めることを確認してください。

## 収録ルール（厳守）
- プレイヤーが使える魔法は**すべて**入れる。作品内で「魔法」「呪文」「術」「PSI」「魔術」「策略」などとして分類されているものが対象。
- 召喚魔法も入れる。fx は `misc`、kind は `summon`、el は `null` にする。
- 次のものは入れない。
  - 敵しか使わない魔法
  - 通常攻撃、武器技、必殺技、物理スキル、パッシブ、アイテム、装備効果
  - 合体技・連携技（魔法の効果があっても入れない）
- 記憶だけで登録しない。WebSearch と WebFetch を使い、できれば2つ以上の資料で照合する。
  - 1つの資料でしか確認できなかったものは、note に「1資料のみで確認」と書く。
  - 資料どうしで値が食い違ったものは、採用しなかった値も note に書く。
- 表記はゲーム内の表記（日本語版）に合わせる。
- 系統と段階（series・tier）は、資料で上位・下位の関係を確認できたものにだけ付ける。名前が似ているだけで同じ系統にしない。
- 説明文は自分の言葉で短く書く。ゲーム内の文章や攻略記事を写さない。
- 文字化けするページは、URLの前に `https://r.jina.ai/` を付けると読める。出典には元のURLを書く。

## 項目の決まり
- **el**（属性）：`fire` `ice` `thunder` `wind` `water` `earth` `light` `dark` `none` のいずれか。**fx が `atk` のときだけ**付け、それ以外は必ず `null`。
  - 作品独自の属性名（火炎・疾風・祝福など）は、systems の elementNames に書く。
  - サイト共通の属性に当てはまらないもの（核熱・念動・万能など）は `none` にする。
- **fx**（用途）：
  - `atk` 攻撃、`heal` HP回復
  - `atkup` 攻撃力アップ、`defup` 防御力アップ、`spdup` 素早さアップ
  - `atkdown` 攻撃力ダウン、`defdown` 防御力ダウン、`spddown` 素早さダウン
  - `ailment` 状態異常、`cure` 状態異常回復、`death` 即死、`revive` 蘇生
  - `barrier` バリア・反射、`field` 移動・探索、`misc` その他
- **kind**（細分類）：effects.json の kinds にあるキーを優先して使う。ない場合は新しいキーを使ってよいが、report に一覧で書く。
- **series**：同じ作品の中で、el・fx・kind が同じなのに別の系統になるものを区別するための名前（例：DQ の炎はメラ系が `null`、ギラ系が `"gira"`）。系統ではない単独の魔法には、自分の id を入れる。
- **tier**：系統の中での段階（1から数える）。単独の魔法は 1。
- **scope**（対象）：`単体` `グループ` `全体` `自分` のいずれか。分からなければ `null`。
- **line**：単体版と全体版が段階ごとに並んでいる場合（アギ系とマハラギ系など）、全体版にだけ `"all"` を付ける。
- **cost**（消費）：作品内の単位を付けた文字列（`"MP 3"` `"PP 2"` `"SP 4"` `"AP 5"` `"使用回数制（Lv3）"` など）。確認できなければ付けない。
- **users**（主な使用者）：作品内の呼び方のままの配列。キャラクター名、ジョブ名、アーキタイプ名、覚えるペルソナや悪魔の例など。3〜5件が目安。確認できなければ付けない。
- **id**：必ず game id を先頭に付ける（`bof2-padamu` のように）。前作と同じ名前の魔法でも、別の id で登録する。
